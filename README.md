# 📚 Library Management System - Database Project

This repository contains the source code for a library management system, developed as a practical project for a university Database Systems course. The application was built using **Python** and the **Django** framework, focusing on data modeling and relational CRUD operations.

## 🎯 Objective
To practically apply database modeling concepts (entities, relationships, and constraints) in a real-world scenario of library administration. This project covers book cataloging, user management, and the tracking of book loans and returns.

## 🛠️ Technologies Used
* Python 3
* Django
* SQLite / PostgreSQL *(Change to the database you actually used)*
* HTML/CSS (Django Templates)
